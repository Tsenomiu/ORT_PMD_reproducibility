# v1.1.0 release-candidate exclusions

The private recovery staging directory was reviewed but was not copied wholesale.
The proposed release contains only selected, path-neutral publication copies and
compact verification data.

The staging inventory contains 120 files. A SHA-256 comparison found 35 staging
files with an identical counterpart already present or deliberately curated in
the release candidate. The remaining **85 staging files were excluded from
byte-for-byte publication**. Some of their scientifically relevant commands or
metadata are represented by smaller path-neutral publication copies; the pathful
private originals remain in the author archive.

The release candidate does **not** contain:

1. raw FASTQ files;
2. BAM or CRAM files;
3. large full VCF/BCF files or full individual genotype matrices;
4. passwords, authentication tokens, Webin credentials, private keys, or other
   secrets;
5. the unpublished excavation report or its controlled source material;
6. the private recovery staging directory, pathful provenance originals, server
   addresses, or licensed individual-level reference coordinates;
7. obsolete or superseded results presented as current, including the rejected
   five-person/full-1000-Genomes READv2 sweep or superseded ancIBD values.

Large TKGWV2 PED/MAP inputs, the EAS frequency resource, raw sequence files,
controlled CT/spatial inputs, and licensed AADR/HGDP/SGDP reference data remain
external. Where needed, the curated documentation records input identities and
checksums without redistributing those files.
