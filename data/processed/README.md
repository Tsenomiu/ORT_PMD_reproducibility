# Processed verification data

Compact processed data for verification, without raw reads or full genotype
matrices.

- `readv2/`: anonymized cohort-normalization values and focal READv2 results;
- `pca/`: publication-safe PCA manifests and validation records;
- `table1/`: output regenerated by the recovered original Table 1 generator.

The private recovery archive, large genomic inputs, and licensed third-party
reference data are not copied here.
