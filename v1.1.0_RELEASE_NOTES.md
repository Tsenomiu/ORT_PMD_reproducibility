# Proposed v1.1.0 release notes

Status: **local release candidate; not tagged, pushed, or published**.

The candidate starts from v1.0.1 commit
`faf187a1733586c216d656389b32f24f416ab12c` and adds a curated,
publication-safe recovery layer for four workflows.

## Added

- TKGWV2 v1.0b provenance, exact four-line compatibility patch,
  processed-input runner reconstructed from successful logs, manifests, and
  exact 16-row validation. The full-UDG × full-UDG bamRefine-5 comparison
  reproduces HRC 0.2356 from 4,517,214 used SNPs.
- READv2 downstream commands, normalization data, sample/cohort documentation,
  and checks for the primary, autosome-only, and transversion-only results.
- Recovered PCA preparation/projection records, path-neutral public inputs,
  method-distance checks, and exact comparison of Figure 7 and Supplementary
  Figures S7–S8.
- The recovered original Table 1 generator, generated output, and 16-row/80-cell
  provenance validation.
- Main-output source mapping, workflow provenance, validation, exclusion, and
  release-candidate file manifests.

## Reproducibility boundary

All reported READv2 values are validated. The exact original primary
BAM-to-genotype command and random state used for pseudo-haploid sampling were
not preserved, so the candidate does not claim exact raw-BAM-to-result
reproduction. See `docs/reproducibility_limitations.md`.

## Data boundary

The candidate includes compact processed verification data but no raw sequence
files, large genotype matrices, controlled archaeological/CT inputs, licensed
individual-level reference data, or unpublished excavation-report content. ENA
study PRJEB112497 remains private during preparation of this candidate.

`v1.1.0_FILE_MANIFEST.tsv` inventories the candidate changes relative to
v1.0.1, excluding itself and the repository-wide `MANIFEST.sha256` to avoid
self-referential hashes. `MANIFEST.sha256` covers every other release file.
