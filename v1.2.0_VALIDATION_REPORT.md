## Boundary and unaffected content

The public repository excludes BAM, VCF, reference and HaploGrep runtime files.
Its deterministic boundary is the path-neutral code, compact aggregate summaries
and checksums. The 36/37 counts are caller-emitted values from the specified
linear-rCRS workflow, not complete breakpoint-independent mitogenome totals.

The mitochondrial correction did not change autosomal PMD correction,
imputation, ancIBD, kinship, PCA, manuscript figures, numbered manuscript tables
or the separate non-UDG mtCont analysis. The separately added Figure 2 intervals
reflect the Reduce18F DeltaALT uncertainty analysis. Historical v1.1.0 and
v1.1.1 release records were preserved unchanged.
