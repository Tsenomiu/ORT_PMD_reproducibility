# v1.1.1 — CI-portability validation patch

This release supersedes v1.1.0 for manuscript citation. It contains a
cross-platform correction to PCA raster validation only.

Canonical rasters were produced with Poppler 25.06.0 and TeX Live 2024. The
failing v1.1.0 GitHub Actions runs used Poppler 24.02.0. Renderer-dependent
anti-aliasing changed PNG bytes even though the underlying numerical outputs
and scientific content were identical.

- No scientific data, processed source values, analysis results, parameters,
  figure content, tables, or conclusions changed.
- Local `canonical-strict` validation remains the default and still requires
  all 20 PCA checks and all three canonical raster SHA-256 matches.
- GitHub Actions explicitly uses `ci-portable`. It retains the same numerical,
  coordinate, source-data, and plotting-input checks; requires each raster to
  be an RGB PNG with the expected dimensions; verifies the canonical fixtures'
  archived SHA-256 values; and applies documented pixel, structure, and ink-
  coverage thresholds.
- A missing, malformed, displaced, or visibly different figure remains a
  validation failure.

TKGWV2 remains 16/16 exact; READv2 remains 43/43; PCA remains 20/20; Table 1
remains 16/16 rows and 80/80 cells; source-data coverage remains 8/8; and
custom-analysis coverage remains 17/17.
